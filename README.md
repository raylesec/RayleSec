##  Projetos de Segurança

###  SOC N1 — Detecção e Investigação de Falhas de Autenticação no Windows

Laboratório desenvolvido para simular uma etapa de **triagem SOC N1** utilizando eventos de autenticação do Windows.

Durante o laboratório, analisei eventos manualmente pelo Windows Event Viewer e desenvolvi um script em PowerShell para automatizar parte da análise.

O projeto realiza:

- detecção de múltiplos eventos **4625**;
- análise de falhas dentro de uma janela de tempo;
- extração de IP, tipo de logon, processo e códigos de status;
- correlação com eventos **4624** de autenticação bem-sucedida;
- classificação inicial para investigação sem assumir automaticamente a existência de um ataque.
